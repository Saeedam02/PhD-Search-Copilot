# Roadmap

## v2.1

- Optional OpenAI File Search / vector-store integration for large candidate archives.
- Better duplicate detection across mirrored vacancy pages.
- Citation-rich supervisor research reports.
- Country-specific funding normalization.
- Calendar export for deadlines and interviews.

## v2.2

- Optional Gmail connector/SMTP adapter behind approval gates.
- Reference-letter tracker.
- Multi-user encrypted workspace mode.
- Rich local web dashboard with filters and approval actions.

## v3

- Learned ranking calibration from user outcomes without pretending to estimate universal admission probability.
- Research-topic embeddings and paper-network similarity.
- Institution/lab knowledge cache with freshness controls.
- Pluggable portal adapters for explicitly supported, terms-compliant systems.
- Evaluation harness for discovery recall, verification precision, hallucination rate, and document QA.

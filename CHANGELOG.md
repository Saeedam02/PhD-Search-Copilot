# Changelog

All notable changes are documented here.

## [2.0.0] - 2026-08-28

### Added

- Autonomous multi-stage PhD search orchestration.
- OpenAI Agents SDK runtime using the Responses API.
- Specialized profile, discovery, verification, fit, supervisor, application,
  review, and interview agents.
- Persistent SQLite opportunity/application database.
- Deterministic hard filters applied separately from semantic ranking.
- Human-approval queue for all external actions.
- Local CV/transcript/thesis/publication ingestion.
- Scheduled autonomous search cycles.
- Application artifact generation and independent QA review.
- HTML dashboard, outcome tracking, and analytics-ready history.
- CI, tests, privacy controls, security documentation, and GitHub templates.

## [1.0.0]

- Initial ChatGPT-assisted PhD search workflow and deterministic ranking tools.

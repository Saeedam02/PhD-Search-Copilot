# Search strategy

The Discovery Agent is instructed to favor high-signal academic sources:

1. official university/research-institute vacancy pages;
2. official lab or professor pages;
3. official funding-program pages;
4. EURAXESS / AcademicTransfer / recognized academic vacancy aggregators;
5. broad web results only as discovery leads.

A lead is not automatically treated as verified. The Verification Agent independently checks the official source whenever possible.

Search queries combine:

- candidate research topics;
- preferred methods;
- requested countries;
- funding terms such as "fully funded", "doctoral researcher", "PhD position", or "doctoral candidate";
- recent/active vacancy wording.
